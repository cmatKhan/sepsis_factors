# sepsisfactorsdb 0.0.0.9000

* `ingest_parallel()` builds the database from per-dataset part files made in parallel (`ingest_controller("local")` or `"slurm"`, with crew and crew.cluster) and merges them with `merge_parts()`; the result equals `ingest_results()`, ids included. Large datasets are split into chunks (`chunk_fits`). The ids are renumbered at the merge (see `vignette("database")`). `ingest_parallel_targets()` is the targets pipeline; `use_ingest()` now writes `_targets.R`, `ingest.yml` and `run_ingest.sbatch` for it (`use_ingest(serial = TRUE)` keeps the serial workflow). A failed build leaves the old database untouched and a deleted database needs no `tar_invalidate()`.
* `ingest_results()` loads datasets sorted by id, so its ids match the parallel build.
* `derive_dataset()` gains `level`, `fit_keys` and `artifact_base`; `load_dataset()` and `load_cross_dataset()` gain `artifact_base`; `derive_cross_dataset()` takes `db_path` and optional `projections`/`out_path`; `example_results()` gains `n_datasets`.

* Schema 4 (`SCHEMA_VERSION` 4) and results output version 2 (`RESULTS_OUTPUT_VERSION` 2). The database is complete on its own: new `meta`, `genes`, `composition_markers` and derived tables (`factor_top_genes`, `fit_scores`, `projection_values`, `driver_genes`, `fit_diag`, `wgcna_dendrograms`, `sample_metadata`, `gene_variance`, `fit_summary`, `method_agreement`, `factor_association`), so the app runs without `stability_artifacts/`. `methods` gains `label`, `color`, `display_order` and `blurb`; `datasets` gains `family`, `family_position` and `hf_collection`; the fixed `CHECK` lists on artifact kinds and `methods.family` are gone; columns and tables no reader uses are dropped (`dataset_artifacts`, `similarity_histograms`, `icasso_membership`, `fit_redundancy`, `factor_variance_models`, `factor_variance`); `fit_artifacts` points only at `loadings` and `scores`; views `v_same_rank_matches` and `v_projections` are new. Results output 2 only adds optional parts to version 1; the dropped columns become optional.
* `derive_dataset()` and `derive_cross_dataset()` build the derived tables from the full artifacts; `ingest_results()` and `ingest_targets()` run them. This is a temporary exception to "no statistics here" (see the root `TODO.md`, section 7).
* `legacy_to_results()` converts the original project's schema-3 database and artifact tree into a results output (temporary).
* `artifact_mode = "symlink"` links artifacts to files that stay where they are, for results on another filesystem.

* First version: loads a `sepsisfactors` results output into the stability database (schema 3) and its artifact directory with `ingest_results()`, `validate_results()`, `load_dataset()` and `load_cross_dataset()`, plus a targets workflow (`ingest_targets()`, `use_ingest()`) and `example_results()`.
