# sepsisfactors 0.0.0.9000

* First version: the fitting and analysis workflow of the sepsis latent-factor project as a package. It fits pca, spca, ica, nmf, cogaps and wgcna on the built-in datasets (or ones added with `use_dataset()`), computes stability, enrichment, variance and projection analyses, and writes a versioned results output for `sepsisfactorsdb`.
